# ぽちょ 物理試作

GitHub Pages でそのまま公開できる静的Webゲームです。

## 公開方法
1. このフォルダの中身を GitHub リポジトリのルートに置く
2. GitHub の **Settings → Pages** を開く
3. **Deploy from a branch** を選び、`main` / `/ (root)` を指定
4. 保存後に発行される Pages URL をスマホで開く

## 操作
- 画面下部の射出ゾーンに出る3つのぽちょのうち1体をタッチ
- 射出ゾーン内で振り回す
- 指を離すとその瞬間の速度で射出
- 射出ゾーンを抜けると3体のジョイントが切れる

## 現在の調整
- スマホ縦画面向け（最大幅520px）
- 最大移動速度あり
- 最大回転速度あり
- 上向き重力は前版より弱め
- 待機中は重力なし
- 掴んでいる間は射出ゾーンから出られない

Matter.js は CDN から読み込んでいます。
