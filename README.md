# ぽちょ 物理試作 — 重力なし版

- スマホ縦画面向け
- 射出ゾーン内で3ぽちょを振り回して投げる
- 常時重力なし
- 射出後は投げた慣性と衝突だけで移動
- 射出ゾーンを抜けると初期ジョイント解除
- 同色同士が接触するとくっつき、同色3つ以上がつながると弾けて消える
- 最大速度・最大回転速度あり

## GitHub Pages
`index.html` をリポジトリ直下に置き、Settings → Pages → Deploy from a branch から `main` / `/ (root)` を指定してください。

Matter.js は CDN から読み込むため、プレイ時にインターネット接続が必要です。
