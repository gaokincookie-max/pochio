## 注意
Matter.js 0.20.0 をCDNから読み込むため、プレイ時にはインターネット接続が必要です。

一部の非常に複雑な履歴条件は、プロトタイプ用の近似記録で判定しています。条件値はプレイ感を見て調整する前提です。


## v0.1.1 監査結果
- 挙動条件: 178件中170件をゲームで有効化。8件は必要な事後判定/サイズ変化等が未実装のためデータに残して無効化。
- 役: 70件中64件をゲームで有効化。6件は成立不能・条件未定義・接触時間計測未実装のためデータに残して無効化。
- 確認ダイアログのキャンセルで復帰不能になる不具合を修正。
- リトライ/リタイア時の統計保存を修正。
- 直前接触相手・第三者から押された履歴の判定順を修正。
- 図鑑は現在有効な役のみ表示。


## v0.1.2 UI調整
- ゲーム盤面と下部HUDを完全分離。
- SCORE / BEST / 残り / NEXT / 設定を画面下部の専用パネルへ移動。
- 解放済み図鑑コメントの文字を濃くして読みやすく調整。

## v0.1.3 弾け頻度調整
- くっつく条件は変更なし。
- 通常の弾け条件へレイヤー別の追加相対速度条件を設定。
  - 大きさ: 8.8以上
  - 色: 7.8以上
  - 表情: 7.4以上
  - 装飾: 7.0以上
- 特殊組み合わせの弾け条件は希少性が高いため追加補正なし。
- 射出後0.4秒は、そのぽちょ自身を起爆ぽちょにするPOP判定を保護。
- 目標: NONE 約50%、STICK 約30〜35%、POP 約15〜20%。


## v0.1.4 大きさPOP切り分け
- 大きさレイヤーのPOP条件7件を一時的に全無効化。
- STICK条件は維持。色・表情・装飾・特殊組み合わせのPOP条件も維持。
- 条件は削除せず data.js / Excel DB に disabled として保存。
- 目的は、過剰な弾け頻度の主因が大きさレイヤーかを実機で切り分けること。

## v0.1.9 3SET experimental
開始時に初期ぽちょ7体を配置します。初期配置処理中は反応判定せず、安定後に履歴を初期化して通常プレイへ移行します。


## v0.1.9 3SET 操作
1回の射出で3体を装填します。3体は射出前のみ柔らかく連結されています。射出ゾーン内で好きな1体を掴んで振り回し、指/マウスを離すと3体の連結が解除され、その瞬間の慣性で飛びます。残り回数は3体まとめて1回として減ります。


## v0.2.0 調整

射出前の3体セットは射出ゾーンから物理的に抜けないよう安全拘束を追加。上向き重力はv0.1.9より約23%弱めています。
