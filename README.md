# ぽちょ prototype v0.1

スマホ縦画面向けの物理パズルゲーム試作です。

## GitHub Pages
このフォルダの `index.html`, `styles.css`, `data.js`, `game.js` をリポジトリ直下へ置き、GitHub の **Settings → Pages → Deploy from a branch** から `main` / `/ (root)` を公開してください。

## 現在の実装
- タイトル / スタート / モード選択 / 図鑑 / 実績
- SHORT 15発 / MIDDLE 30発 / LONG 50発
- スリングショット式の1ぽちょ射出
- 上向き重力、天井で強く慣性を吸収
- さくら・みずいろ・たまご・わかば・ふじ・あんず
- ごきげん・ふつう・不機嫌
- 小・中・大
- 装飾なし / リボン / メガネ / 王冠 / 芽
- 特殊組み合わせ → 装飾 → 表情 → 色 → 大きさ の挙動判定
- 柔らかく、強い力で切れる接着ジョイント
- 接着グループの誘爆
- 70役のデータと得点判定
- NEW表示 / 図鑑保存 / モード別最高得点 / 統計
- ゲーム中設定：続行 / リトライ / リタイア（確認あり）
- localStorageによる保存

## 注意
Matter.js 0.20.0 をCDNから読み込むため、プレイ時にはインターネット接続が必要です。

一部の非常に複雑な履歴条件は、プロトタイプ用の近似記録で判定しています。条件値はプレイ感を見て調整する前提です。
